# После 45 — лендинг с формой заявки

Одна страница: шапка, оффер, форма заявки (имя, контакт, сообщение) и подвал.
Заявки из формы приходят в Telegram.

## Как открыть

Дважды щелкни по файлу **«Запустить лендинг.command»** в этой папке.
Откроется окно Терминала (его не трогай, просто сверни) и страница
http://localhost:3000 в браузере. Чтобы остановить лендинг, закрой окно Терминала.

Нужен Node.js 18 или новее.

## Как подключить Telegram (один раз)

1. В Telegram открой **@BotFather**, отправь `/newbot`, придумай имя и адрес бота.
   BotFather пришлет ключ вида `123456789:AA...`.
2. Открой файл `.env` в этой папке (он скрытый: в Finder нажми Cmd+Shift+. ,
   чтобы его увидеть) и впиши ключ после `TELEGRAM_BOT_TOKEN=`. Сохрани.
3. Напиши своему боту любое сообщение в Telegram.
   Лендинг сам запомнит этот чат, и бот ответит: «Готово: сюда будут приходить заявки».

Ключ бота не публикуй и не отправляй в чаты. Файл `.env` не попадает на GitHub.

## Как устроено

- `index.html` — страница и форма.
- `server.js` — показывает страницу и пересылает заявки в Telegram.
  Ключ бота хранится только на сервере, посетители его не видят.
- Метка `utm_source` из ссылки попадает в заявку как «Источник».
- Защита от спама: скрытое поле-ловушка и не больше 5 заявок за 10 минут с одного адреса.

## Как разместить в интернете

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Tanikkor/posle45-landing)

1. Нажми кнопку выше и войди в Render через GitHub.
2. Render попросит два значения: `TELEGRAM_BOT_TOKEN` (ключ бота) и
   `TELEGRAM_CHAT_ID` (номер чата — он есть в файле `.env` после подключения Telegram).
3. Нажми **Deploy Blueprint**. Через несколько минут лендинг откроется по ссылке
   вида `https://posle45-landing.onrender.com`.

На бесплатном тарифе Render засыпает, если на сайт никто не заходил 15 минут,
и первая загрузка после этого занимает до минуты.

Автор не врач. Материалы носят информационный характер и не заменяют консультацию специалиста.
